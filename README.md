Visualizzatore DICOM moderno per Windows con interfaccia pulita, filtri avanzati, thumbnail, misure e export JPG/DICOM/PDF.

## Download
Scarica la versione Windows dalla pagina **Releases** del repository.

## Funzioni
- Apertura file DICOM singoli, cartelle e ZIP.
- Miniature nella lista.
- Filtri per paziente, periodo e modalità.
- Misurazione distanze e aree.
- Export JPG, DICOM e PDF.

## Installazione
1. Scarica l'ultima release.
2. Avvia il programma.

## Uso rapido
- **Tasto sinistro**: sposta immagine.
- **Rotella**: zoom.
- **Tasto destro**: windowing.
- **Misure**: seleziona distanza o area dal menu.
